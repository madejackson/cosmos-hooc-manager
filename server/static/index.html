Install / Update

Füge den wget-Link aus dem HOOC-Portal ein (Konfiguration → Plattform → Docker Image). Der Manager lädt das Image, importiert es in Docker und startet den Container hooc-connect (host network, NET_ADMIN, /dev/net/tun).

Watchdog

Der Watchdog prüft alle 30 s, ob hooc-connect läuft, und startet/erstellt ihn bei Bedarf neu (wie das Original-hooc watchdog).
